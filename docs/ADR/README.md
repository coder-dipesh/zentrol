# Architecture Decision Records (ADR)

Short, dated notes for decisions that are costly to reverse (framework, hosting, auth).

**Suggested template**

- **Title** — one line
- **Date**
- **Context** — problem
- **Decision** — what we chose
- **Consequences** — tradeoffs

Example topics: “Django templates + static JS for UI”, “PostgreSQL for production”, “Optional shared secret for gesture logging”.
